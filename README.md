# Ishma Khan — Portfolio

Personal portfolio (v1): hero, tech marquee, and numbered project accordion with inline case studies.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Content in typed TS files (`src/content/`)
- Design tokens in `src/styles/theme.ts`

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

```
src/
  app/                 # layout, page, globals
  components/          # Hero, TechMarquee, ProjectsAccordion, ProjectPanel
  content/             # site, tech, projects
  styles/theme.ts      # only place for design values
```
